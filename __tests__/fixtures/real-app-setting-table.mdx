| Setting item | Allowed target | Usage example |
| --- | --- | --- |
| [All APIs allowed] | Allows calling **all** [Admin key: API category](../reference/admin-key-api). | Use this for early development stages or internal environments. |
| [Only specific APIs allowed] | Allows calling **only selected APIs** among [Admin key: API category](../reference/admin-key-api). | Use this when you want to separate and control sensitive APIs. |
| [All APIs allowed except specific APIs] | Allows calling **all [Admin key: API category](../reference/admin-key-api) except the selected APIs**. | Use this when only a few APIs require exceptions. |
